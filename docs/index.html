Built for long recordings

Everything you need to turn a folder of two-hour sessions into text you can search, read and revise from.

  • GPU-first transcription

    Uses faster-whisper with batched inference and the CUDA 12 runtime. Tuned for the NVIDIA T4, L4 and A100 GPUs you get in Google Colab.

    Playback1×
    This tool6–12×

  • Video or audio, no extra steps

    FFmpeg pulls the speech out of video files. Audio files skip conversion and go straight to the transcription engine.

    MP4MKVWEBMMP3WAVFLAC+40 more

  • Pick up where you stopped

    Finished transcripts are detected and skipped on the next run. Results are written to a temporary .part file first, so an interruption never leaves a half-written transcript.

  • Notes, not just transcripts

    Each file produces readable Markdown study notes with timestamp markers, plus standard TXT and SRT files.

From media to text in four steps

The pipeline is small and easy to inspect, so you always know what happened to each file.

  1. 1

    Scan

    Finds video and audio files in your folder and plans the run.

  2. 2

    Extract

    FFmpeg converts video to speech audio. Audio files skip this step.

  3. 3

    Transcribe

    faster-whisper runs batched inference on the GPU.

  4. 4

    Save

    Writes Markdown, SRT and TXT files safely, one at a time.

Start transcribing

Use a free Colab GPU, or run it on your own computer.

  1. Open the notebook in Colab.
  2. Choose a T4, L4 or A100 GPU under Runtime, then Change runtime type.
  3. Run the setup cell, then launch the studio.
Open in Colab 
git clone https://github.com/ASHISH213/whisper-video-studio.git
cd whisper-video-studio
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python colab_studio.py

You also need FFmpeg installed and on your PATH.
